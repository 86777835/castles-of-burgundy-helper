## 3. 实物配件（与手机工具互补，不竞争）

- **分色布袋**：BGG 商店出售专用套装。多帖说它显著缩短开局（[2937510](https://boardgamegeek.com/thread/2937510) 第 7 楼说买了以后开得更频繁），但也有人嫌袋子太小（同帖第 6、8 楼）。
- **内衬**：Folded Space、Meeple Realty、Basically Wooden、自制泡沫板等，评价两极（[1836213](https://boardgamegeek.com/thread/1836213) 33 楼；Reddit [1kdinmf](https://www.reddit.com/r/boardgames/comments/1kdinmf/) 抱怨 Folded Space v2 顶盖不平）。特别版有专门的收纳指南，推荐数超过 100。
- **亚克力地块贴纸**：Etsy 和 BGG 文件，用来弥补背面没有文字。

这说明分拣和收纳的痛点**已有实物解法**。手机端只需要告诉玩家“本局每个袋子要放什么”，不必重复这些方案。

## 4. 可以成立的差异化与尚未成立的假设

**可以成立**：一个中文、手机优先、免安装的系列姊妹站，把下面几件事集中到一处：

1. **本局配置**：版本（2011 / 2019 / 特别版）、人数、模块勾选、公国板（随机或指定，同板或不同板）。
2. **据此生成的开局清单与每阶段补货清单**，并标出英文规则的印错（黑色仓库块数）。
3. **已核实的易错规则**，附页码。
4. **按编号查地块**，分版本标注差异（例如特别版的 #6）。
5. **终局平局判定**。

已有工具在这些点上要么只有英文，要么只做计分，要么不区分版本。

**尚未成立**：玩家愿意在局中逐轮点手机；需要多手机联网房间；需要终局计分器（中英文都已有）；需要单人自动对手（特别版自带 Châteauma，另有 2019 版的打印版 181 赞和网页辅助）。是否做单人模式辅助，请用户决定。
